# Project initializer

`tuil init` is a complete tuil application, not a shell prompt assembled outside
the framework. Its portable stories are defined in
`registry/blocks/init-wizard.stories.tsx`.

The initializer composes the application shell, theme, typed router, form
fields, controlled Select and MultiSelect controls, workflow Stepper,
observable validation operation, status bar, confirmation Dialog, hotkeys, and
keyboard focus traversal. The CLI registers its initializer plugin with a
disposable registration and routes runtime failures through the application
error handler.

## Interactive story

Start on the Project name field, press Enter to continue, choose a template,
toggle optional features, and activate Review project. The final Dialog shows
the selected configuration and the validation operation status before project
creation.

## Static fallback story

The `StaticFallback` story disables interactive terminal capabilities and
renders the same source-owned controls as deterministic text. CLI command
output also supports silent, text, JSON, and static terminal modes.

```tsx
import { InitWizard } from "../components/tuil/blocks/init-wizard"

<InitWizard
  initialName="my-tuil-app"
  onComplete={(answers) => createProject(answers)}
  onCancel={() => exit()}
/>
```

---
title: Registry
description: Source-owned components and blocks installed by the tuil CLI.
---

Registry items are inspectable TypeScript source, grouped into primitives,
layout, navigation, forms, data display, feedback, workflows, themes, and
blocks. Install an item and its declared registry dependencies with:

```npm
npx @mwillbanks/tuil add button badge progress
npx @mwillbanks/tuil add init-wizard
```

The installer resolves the dependency graph, detects destination conflicts
before writing, and preserves unrelated project files. Use `--force` only when
you intend to replace an existing installed item.

The initializer block is documented with its live portable story in
[Project initializer](../components/initializer).

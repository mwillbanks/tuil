## API and events

Render terminal images when the capability profile permits them and deterministic text fallbacks everywhere else.

```tsx
export function TerminalImage({
  source,
  alt,
  columns,
  id: providedId,
  testId,
  ...props
}: TerminalImageProps): ReactNode;
```

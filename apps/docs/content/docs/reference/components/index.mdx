Component pages group closely coupled subcomponents under one behavioral
boundary. Each page includes:

- a Fumadocs Story with representative variants
- components, compound subcomponents, and helpers
- keyboard and focus behavior
- emitted callbacks and runtime events
- a Mermaid lifecycle flow
- an installation and usage example

The [Playground](/playground) renders the portable runtime story catalog one
frame at a time. The [Showcase](/showcase) presents the same catalog as a
filterable gallery.

## API and events

A semantic, focusable terminal action with theme variants, disabled state, and keyboard activation.

  children,
  onPress,
  command,

  focusScopeId,

  disabled = false,
  readOnly = false,
  prefix,
  suffix,
  variant = "solid",
  size,
  unstyled,
  className,
  ...props

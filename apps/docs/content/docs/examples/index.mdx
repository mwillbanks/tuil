The workspace ships eight independently buildable examples:

- `minimal` — application shell and basic output
- `forms` — typed fields, validation, and submission
- `dashboard` — layout, progress, and complex data
- `command-center` — commands, hotkeys, and operations
- `file-browser` — navigation, focus, trees, and virtualized data
- `project-wizard` — forms, workflow state, and confirmation
- `ai-assistant` — streaming operation output and cancellation
- `full-screen` — alternate-screen rendering, an SVG-backed splash image,
  timed loading states, hotkey menus, a responsive workspace, and prompt/status
  regions

Run an example from the repository:

```npm
bun --cwd examples/minimal start
```

Replace `minimal` with any example name above. Each example uses the public
packages and provides a static path suitable for automated validation.

## Full-screen application

Run the complete terminal workspace in a TTY:

```npm
bun --cwd examples/full-screen start
```

The example enters the terminal's alternate screen and restores the previous
buffer when it exits. Its centered splash rasterizes the repository-owned
`logo.svg` and renders the RGBA pixels with 24-bit half-block cells, falling
back to grayscale characters when true color or Unicode is unavailable. After
the timed loading sequence, the layout fills the current terminal height and
responds at compact, regular, and wide widths.

Use `Alt+F`, `Alt+E`, and `Alt+H` (`Option` on macOS) to open the File, Edit,
and Help menus. The prompt submits with `Enter`; `Esc` closes an open menu and
returns focus to the prompt.

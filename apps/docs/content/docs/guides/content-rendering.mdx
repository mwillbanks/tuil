title: Markdown, code, and structured rendering
description: Render content models with search, folding, and copy semantics.
icon: FileCode
---

Parse source into a model before projecting it. Code models carry language,
tokens, diagnostics, folds, and incremental edits. Structured models retain
tree paths and table projections. Diff models support unified and split views.

Search results and copy ranges refer to source positions, not styled terminal
cells. This keeps keyboard, pointer, static-output, and accessibility behavior
consistent across projections.

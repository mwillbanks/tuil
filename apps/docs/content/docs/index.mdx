---
title: tuil
description: A production terminal UI framework for React and Ink.
---

tuil combines composable terminal components with application runtime services,
forms, routing, workflows, operations, plugins, registries, testing, and
portable component stories.

## Start here

Run `tuil init` to create a project, or use `createApp` and
`@mwillbanks/tuil-ink` directly for a custom runtime.

The native `bun run playground` environment is authoritative for input, focus,
resizing, terminal capability, and theme behavior.

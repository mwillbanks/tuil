tuil is a React and Ink framework for terminal applications that need more than
rendered text. It coordinates lifecycle, typed events, services, commands,
focus, hotkeys, routes, forms, workflows, operations, themes, plugins,
source-owned components, semantic tests, and portable stories.

## Install

Use the umbrella package when you want the complete runtime:

```npm
npm install @mwillbanks/tuil @mwillbanks/tuil-ink react ink
```

Focused packages are independently installable. The [package
reference](/docs/reference/packages) documents ownership and compatibility for
each boundary.

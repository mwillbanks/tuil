---
title: tuil
description: A production terminal UI framework for React and Ink.
---

tuil combines composable terminal components with application runtime services,
forms, routing, workflows, operations, plugins, registries, testing, and
portable component stories.

## Start here

Install the runtime and Ink adapter:

```npm
npm install @mwillbanks/tuil @mwillbanks/tuil-ink ink react
```

Create a project with the self-hosted initializer:

```npm
npx @mwillbanks/tuil init
```

You can also use `createApp` and `@mwillbanks/tuil-ink` directly for a custom
runtime.

From a source checkout, the native playground is authoritative for input,
focus, resizing, terminal capability, and theme behavior:

```npm
bun run playground
```

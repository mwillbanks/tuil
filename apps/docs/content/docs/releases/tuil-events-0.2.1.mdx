## Toolchain

The workspace uses Bun 1.4.4 for formatting, type checking, tests, and JavaScript bundles. Oxlint supplies lint diagnostics. Package declarations retain the published TypeScript entry points. Generated starters use the workspace Bun pin and the supported runtime dependency ranges.

## Browser documentation

Documentation and the showcase use Bun builds. The site retains direct documentation links, static search, terminal stories, playground controls, and GitHub Pages paths. The published Storybook adapter continues to support consumer integrations.

## Runtime and validation

Layout projections derive child relationships from their parent records. Invalid geometry and conflicting child metadata fail before the projection changes. Static Ink output closes after the rendered frame. Wheel input reaches the scroll area once. Test lanes distinguish unit behavior, functional integration, and regressions.

See the [testing guide](/docs/guides/testing/) for validation commands.

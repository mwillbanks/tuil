---
title: Agent skills
description: Installable guidance distributed with tuil and its CLI.
---

The published package includes seven Agent Skills:

- authoring tuil components
- building tuil applications
- building tuil forms
- building tuil plugins
- building tuil workflows
- publishing tuil registry items
- testing tuil applications

Inspect the bundle with `tuil skills list` and install it into a project with
`tuil skills install`. Installation is transactional: paths are validated,
collisions are reported before changes, and unrelated skill files are
preserved. Use `--force` to replace only colliding bundled skill directories.

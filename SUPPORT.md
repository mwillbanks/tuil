# Support

tuil is currently a 0.x alpha project. APIs may change between minor releases,
and support is provided on a best-effort basis.

Use the
[support question template](https://github.com/mwillbanks/tuil/issues/new?template=support-question.yml)
for usage questions and help diagnosing an application. Search existing
documentation and issues first, then include the tuil package versions, Bun
version, operating system, terminal, minimal reproduction, and relevant
sanitized output.

Use [GitHub Issues](https://github.com/mwillbanks/tuil/issues) for reproducible
bugs and focused feature requests. Maintenance and response times are not
guaranteed.

Do not post vulnerabilities or sensitive data publicly. Follow
[SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting
form.

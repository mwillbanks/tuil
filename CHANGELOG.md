# Changelog

## tuil 1.0.3

- Upgrade the workspace to Bun 1.4.4 and current dependencies.
- Build documentation and the browser showcase with Bun.
- Restore layout projection integrity, terminal input, and static rendering.
- Generate starter projects with native Bun commands and current dependency ranges.
- Publish curated release notes and qualify package consumers before release.

Historical changes remain in each package's CHANGELOG.md.
